# Uber Eats – Grocery & Food Delivery Intelligence

## 1. Project Overview

The Uber Eats Capstone Project focuses on analyzing food delivery operations, customer behavior, restaurant performance, customer feedback, delivery time, and hourly order demand.

The project uses Python and machine learning techniques to transform raw operational data into meaningful business insights and recommendations.

## 2. Business Problem

Food delivery platforms generate large amounts of data from customers, restaurants, orders, delivery partners, payments, and customer reviews.

Analyzing this data helps businesses understand:

- Which customer groups generate the most revenue?
- How do restaurants perform across different operational metrics?
- What do customers think about the service?
- What factors influence delivery time?
- During which hours is order demand highest?

## 3. Project Objectives

1. Generate and understand synthetic Uber Eats datasets.
2. Clean and preprocess the available datasets.
3. Perform customer and restaurant segmentation.
4. Analyze customer reviews using NLP and sentiment analysis.
5. Predict delivery time using regression models.
6. Forecast hourly order demand using time-series models.
7. Combine analytical results into actionable business recommendations.

## 4. Tools and Technologies

- **Programming:** Python
- **Data Analysis:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **NLP:** NLTK, TF-IDF, Naive Bayes
- **Time Series:** ARIMA, Prophet, Statsmodels
- **Model Storage:** Joblib, Pickle
- **Development Environment:** VS Code, Jupyter Notebook
- **Version Control:** Git and GitHub

## 5. Dataset Description

The project uses seven synthetic datasets:

| Dataset | Description |
|---|---|
| customers.csv | Customer information |
| restaurants.csv | Restaurant information |
| orders.csv | Order transactions |
| deliveries.csv | Delivery details |
| drivers.csv | Delivery partner information |
| reviews.csv | Customer feedback |
| payments.csv | Payment transactions |

## 6. Project Workflow

### Day 1 – Project Setup and Data Generation
Created the GitHub repository, project structure, synthetic datasets, and data dictionary.

### Day 2 – Customer and Restaurant Segmentation
Performed feature engineering and applied K-Means and DBSCAN clustering techniques.

### Day 3 – Customer Sentiment Analysis
Processed customer reviews, applied TF-IDF and Naive Bayes, and compared results with VADER.

### Day 4 – Delivery Time Prediction
Developed regression models to predict delivery time and evaluated their performance.

### Day 5 – Demand Forecasting
Analyzed hourly order demand and implemented ARIMA and Prophet forecasting approaches.

### Day 6 – Business Insights
Integrated analytical outputs, calculated business KPIs, and prepared recommendations.

### Day 7 – Final Documentation and Presentation
Prepared project documentation, final presentation, and GitHub submission.

This project demonstrates how data analytics, machine learning, natural language processing, and time-series forecasting can support business decision-making in a food delivery platform.

The analysis provides a foundation for understanding customer behavior, improving restaurant operations, monitoring delivery performance, and planning demand.
